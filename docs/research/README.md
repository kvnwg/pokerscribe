## Rules

1. B0 is the floor. A new agent version replaces the previous one only if it beats it by 2.5 SE,
   LBR wins less against it, and the result repeats on fresh seeds.
2. Bug fixes for things that are plainly wrong (a misread, folding when checking is free) don't need
   a simulation, but get a regression test.
3. Recorded human or Pluribus actions are observations, never labels of correct play.
4. All testing and automated play stay offline or in environments we own or may use. No auto-play on
   live sites, no detection evasion, no real-money use. The Slumbot API and the GTO Wizard Benchmark
   count as environments we may use, subject to their terms.

## Roadmap (26 Nov 2026)

A solver-based agent: Modicum (heads-up) first, then Pluribus (six-max). SE is standard error, LBR
is local best response, an exploiter that measures how much a strategy can be beaten.

| Phase | Work | Gate before the next phase |
| --- | --- | --- |
| 0 | Correct inputs, capture log, frozen B0 | Done |
| 1 | Duplicate deals, luck adjustment, heads-up simulator mode | SE at least halved; B0 plays heads-up |
| 2 | River CFR solver in Python, push-or-fold | Reference for Phase 4 |
| 3 | Rust core on toy games: rules engine, hand evaluator, CFR library (vanilla, CFR+, Linear, Discounted, Monte Carlo), exact best response | Kuhn value -1/18 and exploitability under 0.001; Leduc matches OpenSpiel; evaluator exact on all 7-card hands |
| 4 | Rust subgame solver, river then turn, Discounted CFR over all combos with card removal | Matches Phase 2, closed-form results and TexasSolver within 0.5% pot EV; under 0.5% pot exploitability; river p95 under 400 ms |
| 5 | Abstraction: 169 preflop classes, postflop potential-aware clustering with earth mover's distance, action menu and mapping rule, LBR exploiter | LBR win rate falls as buckets and sizes are added, then flattens |
| 6 | Heads-up blueprint, Linear Monte Carlo CFR with negative-regret pruning | LBR falls at every checkpoint; beats B0 heads-up by 2.5 SE |
| 7 | Depth-limited search on every postflop decision (Modicum): opponent picks among blueprint and fold/call/raise-biased versions at the leaf; ranges updated every action; off-tree bets added and re-solved | Beats blueprint by 2.5 SE; luck-adjusted Slumbot match; GTO Wizard Benchmark |
| 8 | Six-max blueprint and search (Pluribus) | Each checkpoint beats the last by 2.5 SE in six-max duplicate; exploiters win little; beats B0 six-max |
